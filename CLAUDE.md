# Claude Code in Agent Office

`AGENTS.md` (imported above) has the project, the commands, the restrictions
and the skills.

Personal rules (your language, how you like answers, your goals) go in
`CLAUDE.local.md` next to this file. Claude Code reads it automatically, and
it is not in git.

## How to work in this project

- Code, comments, files and commit messages are in simple English (ASCII only, see `AGENTS.md`).
- Make changes in small steps. Explain each new idea before or after the code.
- The user makes git commits and pushes (see the git rule in `AGENTS.md`).
- If the user corrects the same thing twice, suggest saving the lesson in `CLAUDE.local.md`.
